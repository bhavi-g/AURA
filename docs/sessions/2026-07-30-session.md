## WORKS (verified — how?)
- 63/63 tests passing locally and in CI (both `test` matrix runs + `bench`), confirmed independently after every task/fix, not just from subagent self-reports.
- Manually verified `VERIFIED` end-to-end against `contracts/Reentrancy.sol` with real `solc 0.8.30`/`slither 0.11.3`.
- Final whole-branch review (dispatched on Opus) found and — after explicit approval — fixed two **Critical** security issues, both confirmed closed via independent exploit re-reproduction (not just code reading):
  1. Verification could fail open: a crashed/timed-out analyzer looked identical to "no findings," so a broken analyzer run could yield `VERIFIED` for an untouched vulnerability. Fixed with a control run against the pristine file before trusting the patched result.
  2. `git apply --unsafe-paths` allowed a crafted diff to write outside the temp verification workspace, independent of `--write`. Fixed by canonicalizing diff headers to the target's basename and dropping the flag.
  3. (Important, fixed alongside) relative target paths — the format shown in the README — silently failed to apply; only absolute paths (what every test happened to use) worked.
- Merged as PR #26 (`7d7fec6`), squash, into `main`.
